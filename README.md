# Career Dreamer — Mapeamento Vocacional

Projeto acadêmico de uma interface web para explorar possibilidades de carreira e roteiros de estudos.

## Autor

Guilherme de Sousa Ferreira  
Análise e Desenvolvimento de Sistemas — Braz Cubas

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Recursos da interface

- Formulário com validação de campos.
- Página de resultados com cartões de carreiras.
- Exibição de competências e roteiros de estudos.
- Dados de exemplo para demonstração.
- Layout responsivo.
- Navegação por teclado.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no VS Code.
3. Com a extensão Live Server instalada, clique com o botão direito em index.html.
4. Selecione Open with Live Server.

## Estrutura

- index.html: página inicial.
- resultado.html: página de resultados.
- css/style.css: estilos.
- js/app.js: lógica da página inicial.
- js/config.js: configurações.
- js/dados-exemplo.js: dados de demonstração.
- js/resultado.js: lógica da página de resultados.
- ISSUES.md: registro de problemas e correções.

## Testes realizados

Foram realizados testes manuais das validações, do modal, da exibição
com dados de exemplo, da responsividade no Edge e da navegação com Tab.

## Uso de inteligência artificial

A IA foi utilizada como apoio nas explicações sobre o código,
nas sugestões de correção e na organização da documentação.
Os testes manuais da interface foram realizados pelo aluno.

## Observação

Os dados de exemplo permitem demonstrar a interface sem comprovar
uma integração com um serviço externo. Os resultados têm finalidade
acadêmica e exploratória.
